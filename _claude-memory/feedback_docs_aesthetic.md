Default visual direction for Jeff's web/UI work: a "livelier docs page" — Stripe docs, Vercel docs, Tailwind docs energy. Clean type, generous whitespace, one restrained accent color, content-forward, no hero images, no marketing flourish. Reads like an engineer's notebook, not a writer's portfolio.

**Why:** Jeff framed it as "I am working, not writing — the ideas are important." He confirmed Stripe/Vercel/Tailwind docs as the reference set. He wants the surface to disappear behind the content.

**How to apply:** When building his personal site or any web surface for him, default to docs-style aesthetic: monospace or code-style accents are fine for headers, but no decorative imagery, no gradients, no "personal brand" flourish. If a design choice would look at home in software documentation from a company he respects, it's on-brand; if it would look at home on a Medium author profile, it's off-brand.
